💾 สำรองข้อมูลทุกตาราง — MASARU Purchase Hub

← หน้ารวม
ดึงข้อมูลทุกตารางออกมาเก็บไว้ในเครื่อง ใช้กู้คืน หรือย้ายไปฐานข้อมูลใหม่ได้
ได้ไฟล์อะไร
· JSON — ข้อมูลครบทุกคอลัมน์ ใช้กู้คืน/ย้ายฐานข้อมูล (ไฟล์หลัก เก็บไว้ให้ดี)
· Excel — อ่าน/ทำงานต่อด้วยมือได้ (ตัดคอลัมน์รูป base64 ออกเพื่อให้เปิดไหว)
⚠️ การสำรองข้อมูลก็นับเป็น Egress เหมือนกัน (ประมาณเท่ากับขนาดฐานข้อมูล ~50–100 MB) เทียบกับโควตา 5 GB ถือว่าน้อยมาก แต่ ไม่ต้องกดซ้ำหลายรอบ กดครั้งเดียวพอ
ถ้าต้องย้ายไปฐานข้อมูลใหม่
1. สร้าง Supabase project ใหม่ ในองค์กร (Organization) ใหม่ — โควตานับต่อองค์กร สร้างในองค์กรเดิมจะใช้โควตาก้อนเดียวกัน ไม่ช่วยอะไร
2. รันไฟล์ .sql ที่มีอยู่ใน repo เพื่อสร้างตารางให้ครบ
3. เอาไฟล์ JSON นี้ import กลับเข้าไป (Table Editor → Import data)
4. แก้ SUPABASE_URL + SUPABASE_KEY ในทุกไฟล์ .html ให้ชี้ที่ project ใหม่
